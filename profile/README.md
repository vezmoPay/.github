# Vezmo

Payments, invoicing and multi-currency business tools for companies and freelancers worldwide.

**Live today:** VezmoPay payment processing (cards, ACH, Apple Pay, Google Pay, UPI and Pix), payment links, hosted checkout, invoices, subscriptions and a REST API. Multi-currency account details, business cards, stablecoin and global payouts are in early access.

## Open source

| Repository | What it is |
| --- | --- |
| [vezmo-mobile-sdk](https://github.com/vezmoPay/vezmo-mobile-sdk) | Take VezmoPay payments in your iPhone and Android apps: React Native, iOS (Swift), Android (Kotlin) and Flutter |
| [vezmoPay-wooCommerce](https://github.com/vezmoPay/vezmoPay-wooCommerce) | VezmoPay for WooCommerce: hosted checkout, inline payment element or secure iframe |
